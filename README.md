# Macaé — versão final para TV

[Baixar o ZIP com o HTML offline](https://github.com/kakashilorenco-lab/trabalhofeira/raw/refs/heads/entrega/macae-final-2026-10-21/MACAE-TV-FINAL.zip)

Extraia o ZIP e abra `macae-exposicao-final.html` no Chrome ou Edge. Pressione **F** para tela cheia. A apresentação inicia automaticamente e funciona sem internet.

Espaço: pausa. Setas: capítulos. R: reiniciar. H: controles. S: fontes e direitos das imagens.

Ciclo observado: 80,25 segundos. Sete temas históricos, 12 imagens autênticas, três rodadas de refinamento visual. Datas provisórias e condições de uso permanecem documentadas na apresentação.

Esta branch contém os arquivos de exibição. A prévia animada dentro do ChatGPT não está disponível neste ambiente.
