# Macaé — pacote para Netlify

[Baixar MACAE-NETLIFY.zip](https://github.com/kakashilorenco-lab/trabalhofeira/raw/refs/heads/entrega/macae-netlify-2026-10-22/MACAE-NETLIFY.zip)

1. Extraia o ZIP.
2. No Netlify Drop, arraste a pasta que contém `index.html`.
3. Aguarde a publicação e abra o endereço fornecido pela Netlify.

O `index.html` está na raiz do ZIP. Não é necessário configurar build: imagens, fontes, estilos e scripts estão incorporados. Este pacote contém a versão com motion corrigido. Preserva os créditos e as condições de uso das imagens no painel S.

Pacote testado como hospedagem estática: início automático, imagens, fullscreen e loop, sem erros ou requisições externas. A publicação na Netlify será realizada pelo usuário.
