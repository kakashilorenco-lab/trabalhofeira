# Macaé — Uma história em imagens

Apresentação automática para TV, com imagens reais, linha do tempo e transições de papel.

## Baixar e abrir

1. [Baixe MACAE-TV.zip](MACAE-TV.zip?raw=true). Se o GitHub mostrar a página do arquivo, use **Download raw**.
2. Extraia o ZIP no Windows.
3. Abra **MACAE-TV/macae-exposicao.html** no Google Chrome ou Microsoft Edge.
4. Pressione **F** para tela cheia.

Não é necessário instalar Node, iniciar servidor ou manter conexão à internet.

**Espaço:** pausar/continuar · **setas:** navegar · **R:** reiniciar · **H:** controles · **S:** fontes e créditos.

Esta branch contém o pacote de exibição. O HTML possui imagens, fontes, estilos e scripts incorporados. Os créditos e as condições de uso estão no painel S. São 12 registros distintos; a imagem da estação de 1978 permanece ausente. Preserve as autorias, licenças e condições de uso ao reutilizar os materiais.
